## Purpose

Use this checklist when a scene feels thin, rushed, or oddly weightless even
though the plot events are correct.

The question is not "should this be longer?"

The question is:

> Did the story create a debt and then move on before the reader felt it paid?

## What Counts As A Debt

A story debt is any cost, promise, loss, injury, obligation, or emotional fact
the reader has been asked to care about.

Common Pathwell examples:

- a character gives up an object that carries identity or grief;
- a character is owed truth, apology, repair, or consequence;
- magic creates a residue, draw, wound, debt, or loss;
- a relationship reveal asks for more weight than its setup has earned;
- a scene changes what a character believes about themselves;
- someone dies, disappears, or is denied closure.

## Three Core Questions

Run these against any chapter, scene, or transition:

1. What debt did this scene create?
2. Where does the story show that debt registering on page?
3. If it does not register, is the silence deliberate compression or an
   accidental gap?

If the answer to question 2 is "nowhere," do not add plot first. Look for the
smallest beat that lets the existing cost land.

## Good Debt Payment

Good debt-payment beats usually:

- are body-first, not explanatory;
- use a concrete object, gesture, silence, or changed action;
- give the reader time to feel a cost without naming the theme;
- preserve mystery while making the emotional consequence legible;
- make the next scene feel earned rather than abrupt;
- can name the exact debt they pay.

## Bad Debt Payment

Avoid fixes that:

- explain magic mechanics as a lecture;
- turn grief or growth into a speech;
- add new plot events to solve a weight problem;
- repeat information the reader already has;
- over-resolve a deliberately unresolved loss;
- soften a cost the story needs to remain costly;
- expand a scene that should instead be compressed.

## Compression Test

Some silence is intentional.

Before adding a beat, ask:

- Is the scene lean because it is decisive?
- Is the omission creating useful discomfort?
- Does the next scene already carry the cost clearly?
- Would adding a beat dull a joke, action moment, or eerie Shade scene?

If yes, preserve the silence.

If no, add only the smallest beat needed.

## Drafting Prompt

Use this prompt for future review or drafting tasks:

> Identify one unpaid story debt in this scene. Name the debt, cite the line or
> beat that creates it, explain why the current draft does not pay it on page,
> and propose the smallest body-first beat that would let the reader feel the
> cost without adding plot or exposition.

## Review Output Format

Use one entry per debt:

- Scene/chapter:
- Debt created:
- Current payment, if any:
- Gap or deliberate compression:
- Smallest safe payment beat:
- Plot-change risk:
- Recommendation:

## TASK-020 Example

TASK-020 found the same unpaid-debt pattern in multiple places:

- Shade's nature and sacrifice were too inferential.
- Elizabeth destroyed the diary without enough aftermath.
- Shade disappeared without Elizabeth registering the loss.
- Stansbury's brother/leader role needed visible runway.

The approved fix did not change the plot. It paid existing debts with:

- one Shade grounding exchange;
- a Chapter 12 split for pacing;
- a Stansbury leadership beat;
- a diary/Shade aftermath passage;
- a Coda time anchor.

## Rule Of Thumb

Add meat where the story already made a promise.

Do not add meat just because a chapter is short.
