# Pathwell: early manuscript sources

**Historical creative material, preserved read-only.** This folder exists to show what the author wrote and explored before or alongside later formal revisions. It is **not** the canonical manuscript, a new set of author rulings, or a request to revise the book.

The current book is in [Story/Chapters/](../../Chapters/). The [Story index](../../README.md) distinguishes manuscripts, experiments, and references.

## Rules for these sources

Keep source snapshots unchanged, including mistakes and exploratory material. Add provenance to this index rather than modifying the source. For story facts, consult the current [author decisions](../../Revision/Decisions.md), [Bible interview](../../Interview/README.md), and [chapters](../../Chapters/). For the history of an idea, use these original files as **evidence**, not as a replacement for those rulings.
