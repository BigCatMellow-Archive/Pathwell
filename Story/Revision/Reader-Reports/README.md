# Reader reports

**Status: index, active.** Every independent read of the book: blind readers, informed reviewers and fresh checks. All of it is **evidence, not authority** ([AGENTS.md §1](../../../AGENTS.md#1-authority)); each report is reconciled in the pass or EXP page it names. The [Emergence index](../Emergence/INDEX.md) indexes them by pass.

**Before proposing to cut a line, search the blind reads below for it** ([INS-0002](../../insights/INS-0002-check-blind-reader-logs-before-cutting-a-line.md)): if a blind reader named it as moving, keep it unless a ruling says otherwise. From the repository root:

```text
grep -rn -i "<a few words of the line>" Story/Revision/Reader-Reports/
```

A **blind** reader was given only the chapters, with no records and no goals; any questions came after the reading. An **informed** reader was given goals, rulings or lenses. A **fresh check** reads the reviser's change against the text before it.
