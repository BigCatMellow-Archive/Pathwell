## One current version of anything

Everything outside `Story/Archive/` is current. When something is superseded, it moves to the archive in the same change, with a line in the archive's index saying what replaced it. If two current pages disagree, the order is: James's rulings (the interview and Decisions), then the book's targets, then the Story_Files references; the revision's [README](Story/Revision/README.md#order-of-authority) has the full order.
